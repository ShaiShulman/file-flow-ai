# PURPOSE
Allow user to automatically organize files and subfolder in a subfolder, through their content, file name and other attributes. Specifically designed for legal files. This is done through categories of files and by an agent/chat interface with a UI that shows the actions being done. 

# Features
- Allow user to upload a zip file containing files and folders
- User to automatically categorize files base on predefined categories and extract additional metadata using file name, content and attributes
- User can ask bulk actions on files using their all basic file operations
- All files operations conducted are kept in history (for entire scopre and per files), can be shown in the UI and can be reverted
- All categories and metadata are shown in UI, and also be queries in the chat, and can be overriden manually by user
- process folder can be downloaded as ZIP
- System can also download a batch file or powershell script that include all changes made (after asking about the base folder in the user's local machine), so that changes can be applied to folder on user's local machine.
- Full login of all actions and LLM actions, including discloclosing to user number of tokens each activity requires + cost + time and totals
- All LLM actions will be made in a way that will reduce costs and number of tokens.
